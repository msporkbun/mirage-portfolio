# 🛠️ MIRAGE Tech

To build this project and document my journey, I am using a specialized set of tools:

- **Obsidian:** My primary tool for documentation and building my "diary" and "portfolio"

- **Cursor:** Code editor for building the site.

- **Penpot:** Used for all UI/UX design, prototyping, and design system tokens.

- **OpenRouter:** To leverage advanced AI models for troubleshooting and brainstorming.

- **Opencode:** For managing open-source contributions and versioning.

# 👩🏻‍💻 Get Started


1. Install Cursor

```
brew install --cask cursor
```

2. Install the Plug-In 

```
Obsidian for Cursor
````

3. Clone the repository

```
git clone <repository-url>
```

##### To Preview Note

`cmd` + `shift` + `P` and choose `Obsidian Preview` to view the note in Obsidian.
